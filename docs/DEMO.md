# 校招演示与录屏脚本

演示的目标不是把所有页面点一遍，而是用 6–8 分钟证明三件事：产品闭环完整、复杂交互可靠、对安全和生产环境有边界意识。

## 1. 演示前 10 分钟

```bash
pnpm health
pnpm seed
pnpm build
pnpm start
```

- 使用专用演示数据库和账号，不展示 `.env.local`、Atlas URI、AI key 或终端历史。
- 预先打开首页、提问页、一个有回答的问题和 `/playground`。
- 清除非演示用通知，禁用桌面弹窗，浏览器缩放保持 100%。
- AI 服务可能不稳定时，准备一个预先生成的结果截图，但现场要说明这是降级备案。

## 2. 6–8 分钟脚本

### 0:00–0:40：一句话和架构

> DevFlow 是我基于 Next.js 16 做的开发者问答社区。我不只补了发布、回答和通知闭环，还把 AI 提问、浏览器代码沙箱、可解释推荐和生产可观测性做成了可测试的工程边界。

只展示 [架构图](./ARCHITECTURE.md) 的全景图，不展开所有细节。

### 0:40–2:10：AI 提问工作台

1. 输入一个信息不完整的问题，展示流式评分、缺失项和相似问题。
2. 展示标签建议和“只应用一条 Diff → 撤销”。
3. 技术点只讲三个：NDJSON 流、`AbortController` 取消竞态、CAS 防止覆盖新编辑。

### 2:10–3:40：Code Lab

1. 运行 JavaScript，展示日志和结果。
2. 运行一个超时代码并 Stop，说明父线程持有 Worker 终止权。
3. 切到 HTML 互动模板，再 Fork，说明 sandbox iframe 和 IndexedDB 副本模型。

### 3:40–5:10：问答闭环与推荐

1. 采纳一个回答，切换到回答者的通知深链。
2. 在首页说明“因为你关注 React”的推荐理由，触发无限滚动。
3. 点击“不感兴趣”再 Undo；打开 `⌘/Ctrl+K` 用键盘完成搜索跳转。
4. 说明排序是规则推荐，不冒充机器学习。

### 5:10–6:20：工程化收尾

展示 CI 和文档，用一句话串起来：

> 推荐评分和 Cursor 是纯逻辑测试，组件用 Vitest，关键路径用 Playwright，最后跑 Next.js 生产构建；可观测性事件通过 digest/脱敏指纹定位，事件中不采集用户输入或错误堆栈。

## 3. 面试追问准备

- **为什么不用页码？** Feed 在翻页时持续变化，签名 keyset Cursor 能保持全序和防篡改；它不是数据库快照。
- **AI 返回错了怎么办？** Schema 校验、受控重试、用户逐条接受、可撤销；不自动覆盖草稿。
- **沙箱是否能执行恶意代码？** 不做这种承诺。Worker/iframe 限制权限和消息边界，HTML 同步死循环仍有浏览器限制。
- **为什么不直接上 Sentry/GA？** 先把事件 Schema、采样、脱敏和发送边界做好，默认结构化日志已可运行；外部平台只是可替换的下游。
- **你怎么证明它可靠？** 给出具体故障测试：旧请求竞态、乐观更新回滚、Cursor 篡改、AI 超时、Worker 死循环和重复 Seed。
